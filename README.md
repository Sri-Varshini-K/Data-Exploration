# Excel Data Exploration 

## Project Overview
Basic data exploration and analysis using Microsoft Excel on a product dataset.

## Tasks Performed
- Calculated SUM, COUNT, AVERAGE, MIN, and MAX.
- Categorized product prices using IF.
- Performed conditional analysis using SUMIF and COUNTIF.
- Extracted Product ID details using LEFT, RIGHT, and MID.

## Tools Used
- Microsoft Excel

## Skills Learned
- Data Analysis
- Excel Formulas and Functions
- Data Summarization
- Conditional Analysis
- Text Manipulation

## Conclusion
Gained practical experience in using Excel functions to analyze, summarize, and transform product data.
